# Habitat Sales Analysis Dashboard

A Power BI project for analyzing habitat-related product sales across shopping centers, using advanced DAX calculations, time intelligence, and a normalized data model.

## Key Features

### Data Modeling
- Built a star schema with proper relationships between fact and dimension tables
- Created composite hierarchies (Year > Quarter > Month) and (Environment > Habitat > Product)

### Visualizations
- Clustered column chart comparing Prices and Quantities by Center Type
- Drill-through pages showing center-specific data
- Expandable matrix showing sales trends by Year, Quarter, and Month
- Environmental hierarchy visuals with drill-down support

## Skills Applied

Power BI, DAX, Data Modeling, Time Intelligence, Drill-Through, Data Transformation, Hierarchies, Business Intelligence
